# Passthrough foundries

Does molten iron in iron pipes make no sense to you? Are you tired of neatly arranged and efficient foundry setups? Then this mod is for you!

Foundry mechanics are changed taking inspiration from fusion power. Lava and molten metals can no longer be transported using pipes. Instead, foundries have passthrough pipe connections to pass molten fluids directly between them. This forces Vulcanus factories (at least the molten metal processing part) to be build adjacent to lava lakes, making factories a lot warmer and messier.

Don't forget that you can flip buildings!
